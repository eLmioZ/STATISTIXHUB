TETAPAN GOOGLE SHEETS — Konfigurasi Berasingan Setiap Acara

Setiap acara mempunyai URL Google Apps Script dan kod pemetaan sel tersendiri. Tiada perkongsian URL global dibenarkan.

Langkah Penerbitan Google Apps Script Sebagai Web App:

  1. Buka fail Google Sheets rasmi bagi acara berkaitan, kemudian klik menu Extensions → Apps Script.
  2. Padam kod lalai sedia ada dan tampal kod yang disalin menggunakan butang SALIN KOD GOOGLE APPS SCRIPT bagi acara tersebut.
  3. Tekan ikon Save (Ctrl+S), kemudian klik Deploy → New deployment.
  4. Pilih jenis Web app, tetapkan Execute as: Me dan Who has access: Anyone, lalu klik Deploy.
  5. Salin Web app URL (https://script.google.com/macros/s/.../exec), tampal pada ruangan URL acara yang sepadan di bawah, klik UJI SAMBUNGAN, dan klik SIMPAN.

Nota Penting: Kod Apps Script yang disediakan dalam sistem ini adalah templat rasmi untuk disalin dan diterbitkan di dalam Google Apps Script; ia tidak berjalan secara terus dari dalam pelayar tanpa diterbitkan sebagai Web App.
